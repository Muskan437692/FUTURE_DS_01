## Business Performance Analysis using Power BI

## Project Overview
This project focuses on analyzing business sales performance using Power BI. The goal is to convert raw sales data into meaningful insights by tracking key performance indicators, identifying trends, and evaluating product, category, and regional performance through interactive dashboards.

 ## Objectives
- Analyze overall business sales performance
- Track key KPIs such as total sales, total orders, and total quantity sold
- Identify top-performing products and categories
- Evaluate regional sales performance
- Support data-driven business decision-making

## Tools and Technologies
- Power BI Desktop
- Microsoft Excel
- GitHub
 Key Features
- Interactive Power BI dashboard
- KPI cards for performance monitoring
- Sales trend analysis over time
- Product, category, and regional performance analysis
- Slicers for dynamic filtering
